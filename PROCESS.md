# NetWatch Development Process

## Selected Process Model

NetWatch will use Scrum as its Agile development process.

Scrum was selected because NetWatch can be developed in small features and tested in short iterations. Some technical requirements may change as network scanning and device detection are tested on real networks, so Scrum allows the project to adapt as development continues.

## Sprint Length

Each sprint will last approximately two weeks.

## Sprint 1 Goal

The goal of Sprint 1 is to create the basic network scanning functionality and allow users to identify detected devices.

## Sprint 1 Backlog

- Scan the local network for connected devices
- Display IP address, MAC address, and hostname information
- Allow devices to be marked as known or unknown
- Allow users to assign custom names to devices

## Product Backlog

Future features include:

- Track when devices were first and last detected
- Highlight newly detected devices
- View previous network scans
- Filter devices by known, unknown, online, or offline status

## Project Board

Development is tracked using a GitHub Projects board with the following stages:

- Backlog
