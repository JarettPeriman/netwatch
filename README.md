## Team Members

Jarett Periman

## Project Abstract

NetWatch is a network device monitoring application designed for home users and small organizations. The application will scan a local network and display connected devices along with information such as IP address, MAC address, device name, and connection status. Users will be able to identify devices as known or unknown, assign custom names, and view when devices were first or last detected. The system may also include features such as scan history, alerts for newly detected devices, filtering, and simple network reports. The goal of NetWatch is to provide an easy-to-use tool for monitoring devices on a local network while applying software engineering practices throughout the development process.
